# AI Student Attendance System

Smart Attendance System using FastAPI, PostgreSQL, ArcFace, ONNX Runtime GPU, video processing, and automatic attendance scheduling.

## Main Features

- Student enrollment and face embeddings
- ArcFace face recognition
- GPU inference with ONNX Runtime
- Video-based attendance
- Multiple attendance scans per session
- Automatic attendance finalization
- Manual attendance correction
- PostgreSQL ScanJob queue
- Retry and recovery support
- APScheduler automatic execution

## Important

Student videos, images, model weights, virtual environments, database credentials, logs, and runtime-generated data are intentionally excluded from this public repository.
